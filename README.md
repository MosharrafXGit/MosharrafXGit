Full stack engineer based in Bangalore, building robust end-to-end applications with Java, Spring Boot, and React.js. I focus on clean architecture, responsive UI/UX, secure APIs, and systems that scale seamlessly from frontend to backend.

Currently working on a **multi-tenant real estate platform** — full-stack integration with React dashboards, JWT auth with token rotation, role-based access control, and event-driven architecture.

- 🔭 Currently working on **Full-Stack Microservices & Modern Web Applications**
