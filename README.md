Backend engineer based in Bangalore, building production-grade APIs and distributed systems with Java and Spring Boot. I focus on security, clean architecture, and systems that scale without surprises.

Currently working on a **multi-tenant real estate platform** — JWT auth with token rotation, role-based access control, event-driven notifications, OpenAPI-first design.

- 🔭 Currently working on **Microservices Architecture & Event-Driven Systems**
- 🌱 Exploring **DevOps, Docker & CI/CD Pipelines & Cloud-Native Development**
- 💬 Ask me about **Java, Spring Boot, MySQL, System Design**

### 🏢 Estate Platform Backend
> Multi-role real estate platform with CRM, property management, and lead tracking

| Area | Implementation |
|------|---------------|
| Auth | Phone-based registration, JWT + refresh tokens, OTP verification, token blacklisting (Redis) |
| Security | SHA-256 hashed reset tokens, rate limiting (Bucket4j), @PreAuthorize role hierarchy |
| Architecture | OpenAPI-first (code generation), domain events, specification pattern for search |
| Data | PostgreSQL + Flyway migrations, Caffeine + Redis caching, optimistic locking |
| Observability | Prometheus metrics, structured logging with correlation IDs, audit trail |
| Deployment | Docker + docker-compose, K8s health probes, multi-profile config |

**Tech:** Java 21, Spring Boot 3.4, PostgreSQL, Redis, Kafka, Docker, Prometheus
